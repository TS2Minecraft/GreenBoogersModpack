# Как начать играть: GreenBoogers Modpack

## Что понадобится

| Что | Откуда |
|---|---|
| Лаунчер Fjord Launcher Unlocked | [релизы лаунчера](https://github.com/hero-persson/FjordLauncherUnlocked/releases/latest) |
| Установщик сборки `packwiz-installer-bootstrap.jar` | [релизы bootstrap](https://github.com/packwiz/packwiz-installer-bootstrap/releases/latest) |
| Ссылка на сборку | `https://raw.githubusercontent.com/TS2Minecraft/GreenBoogersModpack/main/pack.toml` |

---

## Шаг 1. Скачать и распаковать лаунчер

1. Открой [страницу релизов лаунчера](https://github.com/hero-persson/FjordLauncherUnlocked/releases/latest).
2. В списке файлов (Assets) скачай:
   **`FjordLauncher-Windows-MSVC-`**

---

## Шаг 2. Первый запуск и аккаунт

1. Запусти `FjordLauncher`
2. Пройди мастер первого запуска. Java лаунчер предложит скачать сам, соглашайся.
3. Добавь аккаунт: **Профиль → Управление аккаунтами → Добавить офлайн-аккаунт** (Add Offline).
4. Введи свой ник и сообщи его администратору сервера, чтобы тебя добавили в вайтлист.

---

## Шаг 3. Создать инстанс

1. Нажми **Добавить новый эксземпляр** (Add Instance) → **Создать новый**.
2. Название: `GreenBoogers`.
3. Версия Minecraft: `<версия из pack.toml>`.
4. Загрузчик модов: `<Fabric / Forge / NeoForge / Quilt>`, версию загрузчика оставь по умолчанию (последняя).
5. Нажми **OK**.

Пока инстанс не запускай.

---

## Шаг 4. Положить установщик сборки

1. Скачай [`packwiz-installer-bootstrap.jar`](https://github.com/packwiz/packwiz-installer-bootstrap/releases/latest).
2. В лаунчере нажми правой кнопкой на инстанс **GreenBoogers** → **Папка** (Folder). Откроется корень инстанса.
3. Зайди в папку **`.minecraft`** (в некоторых версиях она называется `minecraft`).
4. Положи туда `packwiz-installer-bootstrap.jar`.

Должно получиться так:

```
GreenBoogers/
├── instance.cfg
└── .minecraft/
    ├── packwiz-installer-bootstrap.jar   ← сюда
    ├── mods/
    └── config/
```

---

## Шаг 5. Команда перед запуском

1. Правой кнопкой на инстанс → **Настройки** (Edit) → **Пользовательские команды** (Custom Commands).
2. Если есть галочка переопределения глобальных настроек (**Customize / Override global settings**), включи её.
3. В поле **Команда перед запуском** (Pre-launch command) вставь целиком, вместе с кавычками:

```
"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://raw.githubusercontent.com/TS2Minecraft/GreenBoogersModpack/main/pack.toml
```

`$INST_JAVA` лаунчер подставит сам: это путь к Java этого инстанса. Ничего заменять не нужно.

4. Нажми **Закрыть**.

---

## Шаг 6. Оперативная память (рекомендуется)

**Настройки инстанса → Java**:

- Минимум: `2048` МБ
- Максимум: `4096` МБ (для большой сборки можно `6144`, если у ПК от 16 ГБ ОЗУ)

---

## Шаг 7. Первый запуск

1. Нажми **Запуск** на инстансе.
2. Перед игрой откроется окно установщика: он скачивает все моды сборки. Подожди, пока оно закроется.
3. Если установщик предложит выбрать **необязательные моды** (шейдеры, миникарта и т.п.), отметь нужные галочки. Выбор запомнится.
4. После скачивания запустится Minecraft.

---

## Как это работает дальше

При каждом запуске установщик сверяет твои моды со сборкой и сам докачивает новые и удаляет убранные. Тебе ничего делать не нужно: просто запускай инстанс.

Свои дополнительные моды можно класть в `mods/`, установщик их не тронет. Но моды, которые добавляют блоки, предметы или мобов, без такого же мода на сервере приведут к ошибке при входе. Безопасны в основном клиентские моды (миникарта, интерфейс, оптимизация).

---

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| Игра не стартует, ошибка Java | Проверь в настройках инстанса, что выбрана Java нужной версии (для Minecraft 1.20.5+ нужна Java 21, для 1.18-1.20.4 Java 17) |
| Моды не появились в `mods/` | Проверь, что `.jar` лежит в `.minecraft` инстанса, а не рядом с `instance.cfg`, и что команда вставлена целиком |
| Окно «скачайте файл вручную» | Автор мода запретил автоскачивание. Нажми на ссылку в окне, скачай файл и положи его в указанную папку, затем запусти снова |
| Сервер пишет «версии не совпадают» или ошибку модов | Запусти инстанс ещё раз, чтобы установщик обновил сборку. Если не помогло, напиши администратору |
| Не пускает на сервер | Проверь, что ник в лаунчере совпадает с ником в вайтлисте (регистр важен) |
| Установщик не открывается | Проверь, что команда начинается с `"$INST_JAVA"`, в кавычках и без лишних пробелов |
